# Visual Direction

## Visual Thesis

OrbitDock should feel like quiet orbital glass pinned to the desktop: soft transparency, crisp text, small highlights, and no heavy chrome.

## Content Plan

- Primary workspace: desktop zones are the product, not a separate dashboard.
- Secondary context: a restrained settings window for configuration.
- Detail: folder status, active tabs, item counts, and safe-action feedback.
- Final action: tray controls for reload, peek, settings, and exit.

## Interaction Thesis

- Roll-up should be instant and calm, preserving spatial memory.
- Peek should feel like bringing the desktop layer forward, not launching a modal.
- Hover states should clarify clickable files without turning the surface into a busy dashboard.

## Palette

- Base: near-black graphite, not pure black.
- Text: cool white with muted blue-gray secondary labels.
- Accent: per-zone color, defaulting to teal, amber, and violet starters.
- Borders/shadows: low opacity, used to separate from wallpaper without looking like thick panels.

## UI Rules

- Keep zone headers compact.
- Use repeated item tiles only for files/folders.
- Avoid marketing copy in the runtime UI.
- Use status text for real state: empty, offline, copied, moved, or unreadable.
- Prefer direct manipulation over buried settings.
