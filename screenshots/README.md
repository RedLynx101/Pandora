# Product images

The README images are offscreen renders of actual Pandora WPF controls with synthetic files, feeds, and project plans. The overview arranges those controls on an illustrative background. They are not captures of a live desktop and do not prove Windows compositor, Explorer, or monitor behavior.

The isolated WPF test harness produces `pandora-overview.png`, the three `pandora-theme-*.png` images, and `pandora-projects.png`. Appearance settings are rendered by the same harness. See [testing](../docs/testing.md) for the exact command and boundaries.

To refresh: run the harness against the current build, review the resulting PNGs, and copy only the intended images here. Do not use a previous image as evidence of a newly tested build.

Real desktop examples may be added separately. Label them as such and review filenames, task titles, account details, notifications, and wallpaper content before publishing.
